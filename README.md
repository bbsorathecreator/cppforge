# CppForge — генератор C++ кода для VS Code

> **Использование ИИ:** при разработке использовался ИИ-ассистент (Claude, Anthropic).

**Автор:** Шачнев Роман Сергеевич, группа M3115
**IDE:** Visual Studio Code (≥ 1.85)
**Язык реализации:** TypeScript

CppForge — расширение для Visual Studio Code, которое анализирует исходный код C++
и генерирует типовые конструкции, которые долго и скучно писать вручную. Это не
набор сниппетов: плагин разбирает текст программы собственным лексером, находит
перечисления и классы, вычисляет значения элементов `enum`, учитывает пространства
имён и уже написанный код.

## Возможности

| Команда | Горячая клавиша (Windows/Linux · macOS) | Что делает |
|---|---|---|
| **Сгенерировать switch по enum** | `Ctrl+Alt+S` · `Cmd+Alt+S` | Вставляет `switch` со всеми элементами выбранного перечисления |
| **Дополнить switch недостающими case** | `Ctrl+Alt+C` · `Cmd+Alt+C` | Находит `switch`, в котором стоит курсор, определяет перечисление и добавляет только отсутствующие ветки |
| **Сгенерировать toString() для enum** | — | Создаёт функцию `const char* toString(Enum)` |
| **Сгенерировать члены класса** | `Ctrl+Alt+G` · `Cmd+Alt+G` | Конструктор, геттеры, сеттеры, `operator==`/`!=`, `operator<<` по полям класса |

Все команды доступны через палитру команд (`Ctrl/Cmd+Shift+P` → «CppForge») и
через контекстное меню редактора → **CppForge**.

### Что умеет анализатор

- Перечисления `enum` и `enum class` с базовым типом (`enum class Color : std::uint8_t`).
- Полные имена с учётом `namespace` и вложенных классов: `game::Unit::State`.
- Вычисление значений элементов: литералы (`10`, `0x1F`, `0b101`, `1'000`), неявное
  увеличение на 1, ссылки на другие элементы, выражения `1 << 3`, `A | B`, `-1`, скобки.
- **Синонимы** (`Default = Idle`) не получают отдельного `case` — иначе код не
  скомпилируется из-за повторяющихся меток. Синоним указывается в комментарии.
- При дополнении `switch` элемент считается обработанным, если обработан любой из его синонимов.
- Поиск перечислений не только в текущем файле, но и в заголовках рабочей области.
- Разбор полей класса: шаблонные типы (`std::map<std::string, std::vector<int>>`),
  несколько полей в одном объявлении (`int a = 1, *b;`), инициализаторы `= x` и `{x}`,
  массивы, битовые поля, `const`-поля, ссылки. Методы, `static`-поля, `using`,
  `friend`, вложенные типы пропускаются.
- Генерация с учётом существующего кода: уже написанные геттеры и операторы не дублируются;
  у `const`-полей и ссылок нет сеттеров; встроенные типы передаются по значению,
  остальные — по `const&`; контейнеры STL в `operator<<` выводятся количеством элементов.

### Настройки

| Параметр | По умолчанию | Описание |
|---|---|---|
| `cppforge.switch.addDefault` | `true` | Добавлять ветку `default` |
| `cppforge.getterStyle` | `get` | `get` → `getName()`/`isActive()`, `plain` → `name()` |
| `cppforge.searchWorkspaceHeaders` | `true` | Искать enum в `.h/.hpp` рабочей области |

## Пример

До (курсор внутри `switch`, команда «Дополнить switch»):

```cpp
enum Weekday { Mon = 1, Tue, Wed, Thu, Fri, Sat, Sun };

switch (d) {
    case Sat:
    case Sun:
        return "выходной";
    default:
        return "?";
}
```

После — добавлены только `Mon`…`Fri`, перед `default`:

```cpp
switch (d) {
    case Sat:
    case Sun:
        return "выходной";
    case Mon:
        // TODO: обработать Mon
        break;
    // ... Tue, Wed, Thu, Fri
    default:
        return "?";
}
```

## Установка и запуск

```bash
git clone https://github.com/bbsorathecreator/cppforge.git
cd cppforge
npm install
npm run compile
```

Запуск в режиме отладки: открыть папку в VS Code и нажать **F5** — откроется
окно «Extension Development Host» с папкой `examples/`, где лежит демонстрационный
файл `demo.cpp`.

Сборка установочного пакета: `npx @vscode/vsce package` → `cppforge-1.0.0.vsix`,
затем в VS Code: *Extensions → … → Install from VSIX*.
